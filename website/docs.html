Getting started

What Lead Generation does

Lead Generation is a desktop app for Windows and Linux that finds new customers and talks to them for you:

  1. Find businesses on Google Maps (or Apollo), with phone, website, rating and email.
  2. Verify their emails so you only write to addresses that really exist.
  3. Reach out with email and WhatsApp campaigns. The AI can write a personal message for each business.
  4. Reply: the AI Sales Agent answers customers on email and WhatsApp from what you teach it, and hands you anything sensitive.
  5. Control everything by chatting with the AI Assistant, in English or Roman Urdu, on the computer or from your own WhatsApp.
Everything runs on your computer. Your leads, messages and passwords are stored on your computer, not on our servers. Keep the computer on (the app can run in the background) while campaigns and the AI agent are working.

What you need

  • A Windows 10/11 or Linux computer (64-bit) with internet.
  • Google Chrome installed, which Google Maps Search uses.
  • An AI key for the AI features. A free Groq key is enough to start (see AI providers).
  • An email account to send from (Gmail works with an App Password) and, optionally, a WhatsApp number.
Getting started

Install on Windows

There are two Windows downloads on the Download section. Both are the same app; pick one.

Option A: single .exe (easiest)

  1. Download Lead-Generation-x.y.z-portable.exe. If the browser asks, choose Keep.
  2. Move it somewhere permanent, for example a folder Documents\Lead Generation. Don't run it straight from Downloads if you clean that folder.
  3. Double-click it. If you see “Windows protected your PC”, click More info → Run anyway. This appears because the app is new and not yet code-signed; it is safe.
  4. The first start takes a few seconds while it unpacks.

Option B: zip folder (starts faster)

  1. Download Lead-Generation-x.y.z-win-x64.zip.
  2. Right-click it → Extract All → choose a permanent folder (for example C:\Users\you\Lead Generation).
  3. Open the folder and double-click Lead Generation.exe. Right-click it → Send to → Desktop (create shortcut) for a desktop icon.
Keep the app in a folder you can write to (your user folders). Then automatic updates can replace it. Avoid C:\Program Files.
Getting started

Install on Linux

AppImage (any Linux, recommended)

  1. Download Lead-Generation-x.y.z.AppImage into a permanent folder (for example ~/Apps).
  2. Right-click → Properties → Permissions → Allow executing file as program. Or in a terminal: chmod +x Lead-Generation-*.AppImage
  3. Double-click it to start.

.deb (Ubuntu, Debian, Mint)

  1. Download lead-generation_x.y.z_amd64.deb.
  2. Double-click it and press Install, or run sudo apt install ./lead-generation_*_amd64.deb
  3. Open Lead Generation from your applications menu.
Always open the app as your normal user, never with sudo or as root. Otherwise it uses a different, empty profile and your data seems to “disappear”.
The AppImage updates itself. The .deb only tells you when a new version is out, because installing a .deb needs your password.

Automatic updates

From version 1.0.3, the app updates itself, with no button to press.

  • Every few hours it checks for a new version and downloads it in the background. Each download is checked against GitHub's SHA-256 checksum.
  • It installs only when nothing important is running (no search, verification, campaign send or background task) and you are not using the computer, or while it runs in the background.
  • It restarts by itself in a few seconds. If it was running in the background it comes back in the background. You get a notification “Updated to version x.y.z”.

AI Sales Agent

Answers your email and WhatsApp customers like a trained team member, only from what you teach it and on your schedule. It has seven tabs:

Agent tab: on/off and timing

Email agent / WhatsApp agent
Turn the agent on for each channel. It answers replies in your connected inboxes and WhatsApp numbers.
Auto reply
On: replies are sent without asking. Off: every reply waits in Approvals for you.
Ask me for sensitive messages
Complaints, payments, refunds and legal questions always wait for you, even with Auto reply on.
Reply delay
How long to wait before answering, like a person: immediately, 5 / 15 / 30 minutes, 1–2 hours or custom.
Random variation
Moves each reply time by up to this many minutes, so it never looks automatic.
Answer new email senders

Mark WhatsApp messages read
Blue ticks appear when the agent answers.
Working hours
Only reply during your hours and days, in your time zone. Messages outside them are answered when you open.

Below, Agent activity lists every message with its status: Waiting, Sent, Needs you, Failed. Reply now skips the wait.

Easiest way: tell the AI Assistant about your business in chat (“Hamari company websites banati hai, basic package 25,000…”). It saves it here for you.

Find leads

Google Maps Search

Finds businesses on Google Maps with phone, website, email and rating, and saves them as leads.

  1. Type what and where, for example Shoe shops in Lahore or Dentists in Dubai Marina. Popular suggestions help you start.
  2. Choose or type a Category to save them in (for example “Shoes”). Categories are used later for campaigns.
  3. Press Search. A Chrome window opens and businesses appear in the table as they are found. Leave Chrome open; if Google shows a “I'm not a robot” or consent page, complete it in that window.
  4. Press Stop any time; everything found so far is kept.

Emails and verification

  • Find emails from websites: visits each business website (contact pages too) and collects emails. Only businesses with a website can have an email.
  • Verify emails: checks each email with its mail server. green = exists, yellow = risky, red = does not exist.

Table, filters and export

  • Tabs: All businesses, With website, Without website. Businesses without a website are good prospects if you sell websites.
  • Filters: category, business type, rating (3+, 4+ stars), email yes/no. Clear filters resets them.
  • Click a business to see its details or Open in Google Maps.
  • Export: Export all or Export selected, as CSV or Excel. Search history and background tasks are on the right.
“Chrome did not start”.

Install Google Chrome, close any Chrome window the app opened earlier, and try again.

A business shows no email.

Emails come from the business website. If it has no website, or the site shows no email, none can be found. Its phone number is still saved for WhatsApp.

How many results can I get?

Google Maps usually lists about 100–120 places for one search. For more, search smaller areas: “Shoe shops in DHA Lahore”, “… in Gulberg Lahore”.

Outreach

WhatsApp Campaigns

Send messages and follow-ups to your leads, at a safe pace.

  1. New campaign → Basics: a campaign name.
  2. Audience: categories, countries, cities, tags. Option Only leads never contacted. The Matches count shows how many will receive it.
  3. Messages: write your first message. Add message creates variations; each recipient gets one, so wording varies. Insert variables like {business_name}, {contact_name}, {city}, {category}, {website}. Spintax {Hi|Hello} also works.
  4. Follow-ups: Add follow-up with a delay in days. Follow-ups stop automatically when the person replies or opts out.
  5. AI personalisation (optional): the AI reads each lead's website and rewrites your message for them. Add Guidance, for example “mention online ordering; under 70 words”. Uses AI tokens per recipient.
  6. Pacing & safety: delay between messages, campaign daily limit, Randomise delay ±25%, Skip leads contacted by other campaigns, and a Sending window (hours/days in your computer's time zone).
  7. Send from: pick which WhatsApp accounts to use. Check Preview message, then Start now or Schedule.

On the campaign page: recipients with status (queued, sent, replied, failed/skipped), activity log, and Pause, Stop or Delete.

Your computer must be on (the app can run in the background) for scheduled campaigns to send.

Email accounts

The Email page holds your sending accounts and every email sent from them.

Add an account

  1. Add account → enter your email and password. The mail server settings are found automatically and the login is tested.
  2. If it can't find the server, fill SMTP server and Port yourself (for example smtp.yourdomain.com, port 465). Ask your hosting provider if unsure.
  3. Use Send a test email to check it works.

Gmail: use an App Password

  1. Turn on 2-Step Verification in your Google Account (Security).
  2. Open Google Account → Security → App passwords (or search “App passwords”), create one named “Lead Generation”.
  3. Copy the 16-letter password and paste it as the password in the app. Your normal Gmail password will not work.

Categories and rotation

  • Give an account one or more categories: leads in those categories are emailed from it.
  • Rotate accounts in a category: when several accounts share a category, emails take turns between them, which spreads the load.
  • The sent table shows every email with status (sent, replied, sending now, failed). Search by email or business.
The app also reads replies in these inboxes, so the AI Sales Agent can answer them. Mail sent from your own accounts is never treated as a customer.

Troubleshooting

Windows says “Windows protected your PC”.

Click More info → Run anyway. It appears because the app is new and not code-signed yet.

Gmail: “Invalid login” or “Username and Password not accepted”.

Gmail needs an App Password, not your normal password. See Email accounts → Gmail. Remove spaces if you copied it with spaces.

Email login times out.

Check your internet and that your network doesn't block ports 465/587/993. Try another network (for example mobile hotspot) to test.

The WhatsApp QR code won't scan.

Make the window bigger or full-screen so the whole code is visible, keep the phone 20–30 cm away, and wait for a fresh code (it refreshes automatically). On the phone, use WhatsApp → Linked devices → Link a device.

WhatsApp shows disconnected.

Click Reconnect. If it still fails, Log out and scan the QR code again. Make sure the phone has internet.

Google Maps Search finds nothing or stops.

Look at the Chrome window the app opened: complete any “I'm not a robot” or consent page, then search again. Make sure Google Chrome is installed and up to date.

The AI doesn't answer, or says “limit reached”.

Check AI Sales Agent → AI providers → Test connection. Free keys have daily limits. Add a fallback provider or wait for the reset.

The AI agent didn't reply to a customer.

Check: the agent is on for that channel; working hours; the reply delay hasn't passed yet (see Agent activity); the chat isn't in Take over or AI paused; the message wasn't a sensitive one waiting in Approvals; the person didn't opt out.

The app closed but campaigns still send.

That's the background mode. Quit fully from the tray icon → Quit, or turn off “Keep running when the window is closed”.

My data disappeared on Linux.

You probably opened the app as root/sudo. Close it and open it as your normal user.

Something else went wrong.

Settings → Data & privacy → Open logs folder, and send us the newest log file on WhatsApp with a screenshot.
