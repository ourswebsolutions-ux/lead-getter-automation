Install and set up — step by step

1

Download the single .exe

Click Single .exe file above. Your browser may ask whether to keep it — choose Keep.

2

Double-click Lead-Getter-Enterprise-1.0.0-portable.exe. If Windows shows “Windows protected your PC”, click More info → Run anyway (the app is not code-signed yet). The first start takes a few seconds.

3

Prefer the zip?

Right-click the zip → Extract All → open the folder → double-click Lead Getter Enterprise.exe. Keep all files together; the .exe alone does not run.

4

Install Google Chrome

Google Maps Search uses your own Chrome. If you don’t have it, install it from google.com/chrome.

Open the app as yourself, not as root — otherwise it uses a different, empty profile.

4

Install Google Chrome

FAQ

Questions

Where is my data stored?

On your own computer. Leads, conversations and settings are kept in a local database; passwords and keys are encrypted with your system’s keychain.

Do I need to pay for AI?

No — a free Groq key is enough to start (it has a daily limit). For heavy use you can upgrade Groq or use Claude, OpenAI or Gemini with your own key.

Will the AI send something wrong to my customers?

It answers only from what you teach it. It never invents prices or discounts; complaints, payments, refunds and anything it doesn’t know wait for your approval. You can keep Auto reply off so every reply waits for you.

Can I use Gmail?

Yes. Add it with a Google App Password. Microsoft 365, Zoho, GoDaddy, Hostinger, cPanel mail and most others are detected automatically.

Is WhatsApp safe to use?

It links like WhatsApp Web. Keep daily limits low and message people with a real business reason; opt-outs are respected automatically.

Windows says “Windows protected your PC”.

The app is not code-signed yet. Click More info → Run anyway.

Does it work when the window is closed?

Yes. Closing the window keeps it running in the background (tray icon) so the AI agent, campaigns and WhatsApp control keep working. Quit it from the tray icon.
